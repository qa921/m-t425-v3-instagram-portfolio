# M-T425-V3 — Approved portfolio brief

## Objective
Build a responsive creator portfolio from the connected Instagram catalog. Make **Reels**, **Carousel work**, and **Other posts** unmistakable at first glance. Every featured card must expose a direct source permalink.

## Required structure
- Intro / creator statement
- Media kit with only metrics verified from Instagram; label unavailable metrics rather than estimating them
- Featured work (target 10–12 cards)
- Separate Reels, Carousels, and Other galleries
- Search or filters covering the broader reviewed collection
- Collaborations and contact

## Source workflow
Review 24 source items when available from the connected account. Capture id, caption, timestamp, permalink, type/product type, media availability, and valid engagement/reach/video-view fields. Expand every selected carousel into children. Do not use an asset that cannot be fetched reliably; omit the card or provide an explicit unresolved-asset disclosure. Save usable assets beneath stable repository paths such as `public/media/`.

## Correction pass
After a first deployment, re-check ambiguous format classifications, correct direct-source links and impacted navigation, then verify the deployed site and distinguish a live alias from a submitted deployment URL.

## Notes
This repository contains source inputs only. It intentionally has no finished site, deployment, classification result, or copied Instagram assets yet.
